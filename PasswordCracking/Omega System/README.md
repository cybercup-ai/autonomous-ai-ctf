# Omega System

## Description

We need to find the password of a certain admin. From insider info we know the structure of the password hash is Pokemon + Password + 4 additional digits.  The base passwords had no requirements, so there is a great overlap with common wordlists. Here we have an old demo their login system that will allow you to test a login. If you login it will say, "Hello, User/AdminID@Omegas. FAVCOLOR is always great."

## Question 1

We need to find the password of the admin who has an odd number id, favorite color is red, and favorite Pokemon Charizard. Wrap the password in ODUCTF{}
